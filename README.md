## 서버 스크립트 설치 (최초 1회)

1. 새 구글 시트에서 `확장 프로그램 → Apps Script` → 이 폴더의 `apps-script.gs` 전체를 `Code.gs`에 붙여넣기
2. 파일 상단 값 바꾸기
   - `PW` / `PW_MEMBER`: 운영진 / 길드원 비밀번호 (`CHANGE_ME_…`를 실제 비밀번호로)
   - `SECRET`: 아무 긴 문자열 (설정 후 바꾸지 않기)
   - `SPREADSHEET_ID`는 새 시트 ID로 이미 들어가 있음
3. 편집기 상단 함수 선택에서 `setupSheetsOnce` → ▶ 실행 (처음 실행 시 권한 승인 필요)
   - 포털이 쓰는 탭(캐릭터_기본, 캐릭터_스킬_마유, 공지, 경매 구매, 드랍다운리스트, WEB_DATA)이 머리글과 함께 생성됨
   - 실행하지 않아도 첫 저장 때 자동으로 만들어짐
4. 배포: 이미 만든 웹 앱이면 `배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포` (주소 그대로 유지)
5. 페이지 오른쪽 위 상태가 `실시간 · 시트 동기화` 또는 `시트에 저장된 데이터 없음`이면 연결 완료
6. 운영진 비밀번호로 수정 모드에 들어가 길드원을 추가하고 저장 (첫 저장은 운영진이 하기)

> 비밀번호는 서버 스크립트에만 넣고, 이 저장소(공개)에는 올리지 마세요.
